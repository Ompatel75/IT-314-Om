# Product Epics Backlog

| Epic | Stories | Goal |
| :--- | :--- | :--- |
| **E1 — Data Collection & Integration** | US-01–US-05 | Pull raw GitHub activity (commits, PRs, issues, sprint/milestone data) into the platform and attribute it to a configured project/team |
| **E2 — AI-Based Analysis** | US-06–US-11 | Detect bottlenecks, overload, stale issues, and schedule risk, with configurable thresholds and plain-language explanations |
| **E3 — Reporting & Recommendations** | US-12–US-15 | Auto-generate status reports with actionable recommendations, on a schedule, exportable as PDF |
| **E4 — Dashboard & User Interaction** | US-16–US-17 | Give users a single view of project health, plus a way to appeal a flag raised against them |
| **E5 — Access Control & Administration** | US-18–US-21 | Role-based access, core integrations (GitHub/Slack/LLM), signup/login, and admin project/account lifecycle control |
| **E6 — Observability & Auditability (new)** | US-22 | Log system actions (API calls, generated flags, config changes) for admin accountability — currently missing from the backlog above |
